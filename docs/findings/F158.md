## F158

**Verified** (dev container, gnupg 2.4 / gpgv): the container has `gpg` and `gpgv` but **no `gpg-agent`**, so `gpg` cannot
generate a key or sign, and a self-test cannot make a test key with `gpg --quick-generate-key`. `gpgv` only verifies, so it works.

```
$ command -v gpg gpgv gpg-agent
/usr/bin/gpg
/usr/bin/gpgv
```

Consequence: fixtures that need a signed file build keys and detached signatures with `scripts/lib/openpgp_ed25519.py`
(stdlib only, throwaway keys from fixed seeds, public keyring files). `gpgv` accepts them, refuses a changed file and refuses a
signature by a key not in its keyring (controls `badsig2` and `other` in `scripts/test-vm-image.sh`).
