## F118

Descriptors of the `systemd-creds` child. Status: **verified** (run in the dev container, systemd 257.13, bash 5.2).

| Question | Answer | Status |
|---|---|---|
| Does a child of the service's plain `Command` inherit descriptors? | Yes, every descriptor without close-on-exec. The test holds descriptor 7 (opened by the shell that re-runs the binary) and a plain `Command` running a substitute program that prints `/proc/$$/fd` shows `[0, 1, 2, 7]`. | verified |
| Does the fix close them without `unsafe`? | `SystemdCreds::run` starts `/usr/bin/bash -c '<close every /proc/self/fd entry above 2>; exec "$@"' close-fds <program> <args>`; the substitute then shows only `[0, 1, 2]`. The program and its arguments are positional parameters, never part of the script text; stdin, stdout and stderr are unchanged. | verified |
| Does the test fail without the fix? | With the script reduced to `exec "$@"`: `the child inherited descriptors: [0, 1, 2, 7]`. | verified |
| Launcher missing | The spawn fails (`ENOENT`), which `decrypt_cli` maps to `CredsError::Unavailable`: the transient name, no signature (`transient::missing_launcher`). A launcher that cannot `exec` the command exits 126/127; `run` treats that as a failed start, as before the launcher. | verified |
| Does the device TCTI (`/dev/tpmrm0`) leak the same way? | Not examined in the TSS source. F117 verified the leak for the `swtpm` TCTI sockets; the fix is not dropped, as the contract requires. | inferred |
| Is the launcher reachable under the shipped unit? | `/usr/bin/bash` is executable here (`test -x /usr/bin/bash`). The unit has `ProtectSystem=strict` (read-only, still executable), `SystemCallFilter=@system-service` (allows `execve`), and `/proc/self/fd` is in `ProcSubset=pid`. `systemd-analyze verify data/custodio.service` cannot run the daemon here (no installed binary), so the run under the unit is proven at the checkpoints (F132/F146). The packages do not list `bash` as a dependency yet (Essential on Debian, in the base set on Fedora and Arch). | partly inferred |
