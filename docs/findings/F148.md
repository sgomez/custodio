## F148

M4 acceptance 14 (`docs/manual-acceptance.md` section 21) in a VM without a TPM, run on 2026-11-07 by an agent on the
person's behalf, driving the VM over SSH and its desktop with `xdotool` and screenshots. Pass. Verified unless marked
inferred.

Machine: lab VM `xubuntu2604` (KVM, Xubuntu 26.04.1, XFCE on X11, kernel 7.0.0-38-generic), no TPM device in the
domain, `ls /dev/tpm*` finds nothing. polkit 127 with the MATE authentication agent, LibreOffice 26.2.6.3,
libnss3-tools 3.120. Package `custodio 0.1.1~rc.1-1` (`just package version=0.1.1-rc.1` at c07d02f, the package of
F147's upgrade). Test CA and `rsa2048.p12` as in section 1.

| 1 | import output | pass | `Storage: encrypted-host. This key is weaker than a TPM key: this machine has no TPM, so the key is a file encrypted with the host key. Root, and anyone with a copy of /var/lib, can use it.`, equal to the page's text |

  `FAILED to authenticate` line; the second import passed.
