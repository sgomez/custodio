## F144

The documented journal queries against the real journal, debian13 guest, packaged service (2026-11-06; swtpm, lacking, none). **Verified** by `just e2e-cases debian13 'journal-kind-*'` in the three modes.

- **Old-format purge.** Files without the record magic (`0x30 0x82 ...` sentinel bytes, as `crates/custodiod/tests/purge/rig.rs`) placed as root in `/var/lib/custodio/<uid>/<id>` (+ `<id>-cert`), owner and group
  copied from alice's area, mode 0600, area 0700 (bob's is created), then `systemctl restart custodio`: the service purges at start-up, one `purge`/`purged` entry per key with `CUSTODIO_OWNER_UID`, no
  `CUSTODIO_UID`; the files are gone. Four keys (two owners, one with and one without a certificate each) gave 4 entries on the operation query and 2 on each owner query.
- **`key_lost`.** Flipping the last byte of the stored record (`/var/lib/custodio/<uid>/<id>`, root, original kept with `cp -p` and put back) gives D-Bus `KeyLost` on `Sign` and a `sign`/`signing_failed`/`key_lost`
  entry with the key's kind, in all three modes (kind `tpm` in swtpm and lacking, `encrypted-host` in none). The record still parses (the byte is in the protected part), the key signs again once the file is back.
- **`temporarily_unavailable`.** swtpm and lacking: the drop-in names a socket that does not exist (`tf_point "$TF_MISSING"`, F139's "no TPM"): `Sign` gives `TemporarilyUnavailable`, entry with
  `temporarily_unavailable`, kind `tpm`; back with `tf_point "$TPM_SOCK"`. none: `systemctl stop systemd-creds.socket` (`tf_credentials_down`): same error and entry, kind `encrypted-host`. No second swtpm needed.
- **Denied signature.** With the agent in `deny` mode `Sign` gives `com.rfirma.Custodio1.Error.PolkitDenied`; its entry is `denied`, not returned by the cause queries.
- **Forged entries.** `jo-forge.py` as root and as alice (journald takes the `CUSTODIO_*` fields and `MESSAGE_ID` from any sender, sets `_UID` and `_SYSTEMD_UNIT` itself): the documented queries name the unit and the service user
  and return none of them. `tpmclear-sign.py` makes exactly one `Sign` call, so the failed signatures are counted exactly (pkcs11-tool makes two, F140).
