# F52 — Written manual acceptance steps for the M2 machines

## Scope
Documentation only. `docs/manual-acceptance.md` gains M2 parts (SPEC.md acceptance steps 12 to 15)
for four machines, written so a person can follow them without this repository's history:
`fedora44`, `bazzite`, `omarchy`, `ubuntu2404`. The existing M01 content stays and still reads
correctly; the title and intro are adjusted so the page covers both milestones. Ubuntu 24.04 is
still supported (F41 found polkit 124 reads ProcessFD, see `docs/findings.md`), so its part is written.

Left for other features: running the steps and recording results (F54 fedora44, F55 bazzite,
F56 omarchy, F57 ubuntu2404 or whichever ids features.json gives them), the installation commands'
own explanation (F51, `docs/install.md`; the steps link to it rather than repeat it), and the
journalctl query itself (`docs/audit.md`; the steps link to it).

Environment: the dev container has none of these machines, no SELinux, rpm-ostree or graphical
agent (SPEC.md "Limits"). So nothing in the new text can be run here. Every command not copied from
a script, `docs/install.md` or `docs/audit.md` is marked **unverified**, as the existing page does.

Size: fits one session (about five steps).

  a copy missing any one of the words fails it (control in the new test).
- Every run records OS release, kernel, bus daemon and version, polkit version and package file
  names, with a command for each, and the result form has a field for each → `test-docs-manual.sh`:
  each machine's part (found by its heading) contains all five items, and the form lists them; a
  control with one item removed from one machine's part fails.
- fedora44: SELinux enforcing checked first (`getenforce`), dnf install of the `.rpm`, `.p12`
  import, Fedora's Firefox lists the certificate without manual registration and does TLS client

  the one in `docs/audit.md`; controls: no `ausearch`, no `getenforce`, altered query.

  still sign after each reboot, no SELinux denial → test checks each item in the bazzite part;
  controls: no replace step, no reboot after the OS update.
